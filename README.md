> 🧠 一款面向心智障碍者就业支持场景的 AI 辅助沟通工具
>
> An AI-powered communication assistant for supporting employment of individuals with intellectual and developmental disabilities

## ✨ 功能特性 | Features

### 📋 向员工下达指令 (Give Instructions to Employees)

主管输入日常口语化指令，AI 自动翻译为适合心智障碍员工理解的版本，生成包含提词剧本、视觉步骤卡、感官预警等内容的结构化沟通卡片。

### 🔍 员工状态解读 (Interpret Employee Behavior)

主管描述员工的具体行为表现，AI 基于 FBA（功能性行为评估）框架进行行为归因分析（SEAT 模型），生成干预建议和禁忌话术提醒。

### 📅 任务规划 (Task Planning)

主管输入一个完整的工作任务，系统自动拆解为分步任务卡序列，支持进度追踪、休息节点自动插入、全屏展示给员工等功能。

### 📊 岗位适配评估 (Job Fit Assessment)

输入员工画像和目标岗位信息，系统从认知负荷、感官环境、社交要求、任务结构化四个维度评估匹配度，生成入职支持建议和风险预警。

### 👤 员工管理 (Employee Management)

支持多主管多员工管理，为每位员工建立包含障碍类型、工作记忆、感官触发词、沟通偏好等维度的动态画像。

## 🚀 部署到 Streamlit Community Cloud | Deploy to Streamlit Community Cloud

### 前提条件 | Prerequisites

- GitHub 账号
- Streamlit Community Cloud 账号（[免费注册](https://streamlit.io/cloud)）
- OpenAI API Key（或兼容 OpenAI 格式的 API）

### 部署步骤 | Deployment Steps

1. **Fork 或克隆本仓库到 GitHub**

2. **在 Streamlit Community Cloud 创建新应用**
   - 登录 [Streamlit Community Cloud](https://streamlit.io/cloud)
   - 点击 "New app"
   - 选择对应的 GitHub 仓库和分支
   - 主文件设置为 `app.py`

3. **配置环境变量（Secrets）**
   - 在应用的 Settings → Secrets 中添加：
   ```
   OPENAI_API_KEY=sk-your-api-key-here
   OPENAI_API_BASE=https://api.openai.com/v1
   OPENAI_MODEL=gpt-4o
   ```
   - `OPENAI_API_BASE` 和 `OPENAI_MODEL` 为可选项，不填则使用默认值

4. **部署完成**，点击应用链接即可访问

### 本地运行 | Run Locally

```bash
# 克隆仓库
git clone https://github.com/your-username/tongpin-mind-assistant.git
cd tongpin-mind-assistant

# 安装依赖
pip install -r requirements.txt

# 设置环境变量
export OPENAI_API_KEY="sk-your-api-key-here"
export OPENAI_API_BASE="https://api.openai.com/v1"  # 可选
export OPENAI_MODEL="gpt-4o"  # 可选

# 启动应用
streamlit run app.py
```

## 🏗️ 技术架构 | Technical Architecture

- **前端框架**：Streamlit（Python）
- **AI 引擎**：OpenAI API（兼容格式）
- **Prompt 架构**：三层 Prompt（障碍类型规则层 + 员工画像层 + JSON 输出格式层）
- **行为分析**：SEAT 归因模型（Sensory / Escaping / Attention / Tangible）
- **认知负荷预警**：双计数器机制（逆向计数 + SEAT S/E 风险计数）
- **JSON 容错**：三级降级解析（strip markdown → extract {} → degradation card）
